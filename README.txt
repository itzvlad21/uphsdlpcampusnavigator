Project Overview
The UPHSD-LP Campus Navigator is a web-based application designed to address navigational challenges and enhance campus accessibility at the University of Perpetual Help System DALTA - Las Piñas. It provides an interactive 3D campus map featuring virtual walkthroughs, location previews, and updated institutional information to assist students, faculty, and visitors, especially newcomers.
Features
 * Interactive 3D Campus Map: Explore the campus virtually with a detailed 3D model.
 * Real-time Navigation: Get directions to buildings, classrooms, offices, and other key facilities.
 * Location Previews: View detailed descriptions, images, and panoramic views of various campus locations.
 * Voice-Guided Navigation: Supports voice guidance to help users reach their destination.
 * Guest and Member Access: Different access levels for guests and university-affiliated users (students, faculty, staff).
 * Search Functionality: Easily search for specific locations within the campus.
 * Responsive Design: Fully optimized for use on desktops, laptops, tablets, and mobile devices.
 * Real-Time Updates: Provides up-to-date information on campus conditions, events, and facility availability.
Technologies Used
The UPHSD-LP Campus Navigator was developed using the following technologies:
 * Frontend: HTML, CSS, JavaScript, Three.js, React.js
 * Backend: Node.js, Express.js
 * Data Management: Static JSON files and API integration
 * Design Methodology: Agile methodology, emphasizing iterative prototyping, user-centered design, and continuous refinement.
System Requirements
To run the UPHSD-LP Campus Navigator efficiently, the following specifications are recommended:

Installation and Running
To set up and run the application locally, follow these steps:
 * Install Dependencies:
   npm install

   This command will install all the necessary project dependencies.
 * Run the Application:
   npx vite

   This command will start the development server and run the application. You can usually access it in your browser at http://localhost:5173 (or another port if specified).
 * Build the Application:
   npx vite build

   This command will compile and optimize the application for production, creating a dist folder with the build output.
 * Preview the Built Application:
   npx vite preview

   After building, this command allows you to preview the production build locally.
How to Use
The application is accessible through a web browser. No additional software installation is required.
 * Open your web browser.
 * Navigate to the UPHSD-LP Campus Navigator URL: https://uphsdlpcampusnavigator.onrender.com/.
 * Upon loading, you can choose to "Continue as Guest" for basic navigation or "Login as Student" for full access to features.
 * Use the interactive 3D map by tapping/dragging to look around, pinching to zoom, and clicking on markers for detailed information.
 * Utilize the navigation panel to select starting and target destinations for real-time directions.
For detailed instructions, please refer to the "Help & Support" section within the application or directly access the help page: https://uphsdlpcampusnavigator.onrender.com/help.html.
