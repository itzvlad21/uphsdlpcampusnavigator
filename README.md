
# UPHSD-LP Campus Navigator System

The **UPHSD-LP Campus Navigator** is a web-based interactive 3D campus map application designed to help students, faculty, staff, and guests efficiently navigate the University of Perpetual Help System DALTA - Las Piñas campus. It provides real-time directions, location information, and accessibility routes through a user-friendly interface.

## 🔧 Features

- 🔍 Explore an interactive 3D map of the UPHSD-LP campus  
- 🏢 View detailed information on buildings and facilities  
- 🧭 Use basic and real-time navigation (guest or logged-in user)  
- 🔊 Voice-guided directions for ease of use  
- 📱 Fully responsive — works on desktops, tablets, and mobile devices

## 🚀 Getting Started

### 📦 Installation

Clone the repository and install the required dependencies:

```bash
npm install
```

### 🔄 Development Server

To start the development server:

```bash
npx vite
```

### 📦 Build for Production

To build the app for deployment:

```bash
npx vite build
```

### 👀 Preview the Production Build

To locally preview the production build:

```bash
npx vite preview
```

## 🛠 Technologies Used

- **Frontend:** HTML, CSS, JavaScript, Three.js  
- **Backend:** Node.js  
- **Data Management:** Static JSON files and APIs  
- **Framework:** Vite (for development and build)
